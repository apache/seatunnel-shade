Apache SeaTunnel Shade 3.0.1 Release Notes

Overview
--------
Apache SeaTunnel Shade 3.0.1 upgrades Hazelcast to 5.1.7 and corrects the
Jackson version bundled in the Hadoop3 Uber JAR.

New Features
------------
- N/A

Improvements
------------
- Upgrade Hazelcast from 5.1 to 5.1.7, replacing the bundled JSON-java
  20201115 with the public-domain 20230227 release.
- Update the Hazelcast third-party notices and preserve the bundled
  JSON-java version metadata.
- Include the SeaTunnel patches and updated third-party notices in the
  Hazelcast source JAR.

Migration Notes
---------------
- To upgrade all Shade dependencies from 3.0.0, set seatunnel.shade.version
  to 3.0.1 and update the Hazelcast library version to 5.1.7.
- If you pin the affected artifacts directly, use these Maven coordinates:
  - org.apache.seatunnel:seatunnel-shade-hazelcast:5.1.7-3.0.1
  - org.apache.seatunnel:seatunnel-shade-hadoop3-uber:3.1.4-3.0.1

Bug Fixes
---------
- Bundle relocated Jackson Core and Databind 2.15.4 in Hadoop3 Uber to
  match the Shade source build. The 3.0.0 artifact on Maven Central
  contained 2.13.3.
- Restore tracking of departed member UUIDs in SeaTunnel's patched
  Hazelcast MembershipManager.
